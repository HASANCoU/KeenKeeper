## 📖 Project Description
**KeenKeeper** is a modern web application that helps users manage and maintain meaningful relationships with their friends. It allows users to track interactions, monitor communication gaps, and stay consistent in keeping connections active.

---

## ⚙️ Technologies Used
- Next.js (App Router)
- React.js
- Tailwind CSS
- DaisyUI
- JavaScript (ES6+)
- JSON Data

---

## ✨ Key Features

### 📇 Friend Management  
Users can view and manage a list of friends with details like name, bio, and contact information.

### ⏰ Interaction Tracking  
Tracks the number of days since the last interaction to help users stay connected.

### 🎯 Reminder & Goal System  
Allows users to set communication goals and identify overdue interactions.
